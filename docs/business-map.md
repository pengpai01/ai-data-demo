# 星澜诊断业务地图

与 `prototype-v1.3.md` 第 2 节一致。下面只把实现时选定的可逆默认写清楚，不改已锁定口径。

数据全部虚构。销售 100% 通过代理商。文案和表里不把医院、体检中心当作发货、回款或应收的客户，也不做直营对比。

## 维度

| 维度 | 层级 | 本演示怎么用 |
|------|------|----------------|
| 时间 | 年 → 季 → 月，流水到日 | 经营月为 2025-11 至 2026-10。账龄只用月末快照 |
| 组织 | 大区 → 省区 | 主切大区：华东、华南、华北、西南、西北。省区写在 `dim_region.province`，报表不按省区下钻 |
| 产品 | 产品线 → 产品类 → SKU | 产品线三条：试剂、仪器、服务 |
| 客户 | 等级 → 代理商 | 每一行都是代理商。只有 `customer_tier` A/B/C。没有 `customer_type`，没有 `channel` |
| 账龄 | 桶 | 未到期、1–30、31–60、61–90、90+ |

「上个月」= 最近一个完整自然月。演示默认 2026-10，对比月 2026-09。不写关账日。

## 指标口径

**主口径：销售回款率**

销售回款率 = 统计期内实际回款额 ÷ 统计期内净销售额

- 回款额：按回款日归属，挂到发票、代理商、大区和产品。
- 净销售额：码洋 − 商务折扣，按出库日归属。净销售 100% 来自代理商。
- 环比用百分点（pp）。「下降最快」= 销售回款率 pp 下降最大。
- 净销售占比 = 该切片本期净销售额 ÷ 公司本期净销售额。占比 < 5% 不参与「下降最快」，追问里仍可查看。占比分母始终是公司整体，不随切片改。
- 大区和产品线都算。默认展开下降更快且占比 ≥ 5% 的那个。并列时展开大区。另一个一键切换。

**辅助口径：到期回款率**（KPI 和追问可用，不作主结论）

到期回款率 = 统计期内实际回款额 ÷ 统计期内到期应收额

到期应收额 = 到期日落在统计期内的发票原净额，含已经回款的发票。到期日 = 出库日 + 该代理商 `payment_terms_days`。分子仍是期间全部回款，不改成「只统计这些发票上的回款」。

**其他已实现指标**

| 指标 | 口径 |
|------|------|
| 出库额 | 码洋合计，即 `list_amount`，按出库日 |
| 出库量 | 维表上的数量，财务结论以金额为准 |
| 折扣额、折扣率 | 折扣率 = 折扣额 ÷ 码洋 |
| 应收余额 | 该月末快照未清金额合计 |
| 本期新增应收 | 本期净销售额。一笔出库一张发票 |
| 逾期余额 | 快照里账龄不是「未到期」的未清金额 |
| 逾期率 | 逾期余额 ÷ 应收余额 |
| DSO | 期末应收余额 ÷（近 3 个自然月净销售额合计 ÷ 这 3 个月的日历天数）。窗口不满 3 个经营月时，结果为「本数据无法支持」 |
| 加权平均账龄 | Σ 未清金额 ×（月末 − 发票日）÷ Σ 未清金额。只描述快照 |
| 平均回款天数 | 近 6 个月已回款金额加权的（回款日 − 出库日）。未回款发票不进入平均 |
| 前 5 家应收集中度 | 应收余额最高的 5 家代理商未清金额 ÷ 应收余额 |
| 新代理商 | 首次出库日 ≥ 统计月往前 11 个月的当月 1 日。2026-10 的窗口起点是 2025-11-01 |
| 老代理商 | 首次出库日早于该窗口 |
| 活跃代理商 | 期间有出库，或期末有应收。本页 KPI 不单列这一项 |

应收月环比：变动 = 本期新增应收 − 本期回款 + 其他。其他 = 期末 − 期初 − 新增 + 回款。本数据没有退货和坏账，其他应为 0。

本版不做：承诺回款、退货、坏账核销、代理商实盘库存、汇率、直销客户。冲量只用公司侧出库和净销售。

## 归因路径

先算，再写。模型不估数。

1. **定位切片**  
   各大区、各产品线分别算销售回款率 pp 变化。占比 ≥ 5% 的集合里各取下降最快的一个。默认展开变化更大的视角。
2. **率变分解**  
   回款额变化贡献 =（本期回款 − 上期回款）÷ 上期净销售额。  
   净销售额变化贡献 = 本期回款 ÷ 本期净销售额 − 本期回款 ÷ 上期净销售额。  
   两项相加 = 销售回款率环比。未四舍五入时恒等；页面展示到 0.01pp。
3. **交叉贡献**  
   大区问题下按产品线拆，产品线问题下按大区拆。  
   贡献 = 子切片本期回款 ÷ 父级本期净销售额 − 子切片上期回款 ÷ 父级上期净销售额。  
   贡献额 = 贡献 × 父级上期净销售额。各子项贡献相加 = 父级环比。
4. **代理商与账龄**  
   代理商用同一套贡献，按贡献从低到高排列。账龄迁移只比较本月末与上月末快照的金额和占比。
5. **辅助对照**  
   只展示算得出来的事实：月末 7 日和月初 7 日净销售占比、折扣率变化、本月到期发票及月末仍未收回的金额、到期回款率。
6. **原因说明**  
   模型只根据 2–5 的事实写 4–6 句，并使用事实里已经列出的计算信号。信号是阈值，不是估算：

   | 信号 | 何时出现 |
   |------|----------|
   | 冲量出货抬高分母 | 净销售增加，净销售额变化贡献为负，且其绝对值至少占环比绝对值的 25% |
   | 大代理商延期 | 拖累前 3 名都是 A 级，且每家净销售上升、回款额下降 |
   | 账龄恶化 | 90+ 金额上升，或逾期金额上升 |
   | 促销折扣升但回款未跟 | 折扣率上升至少 1 个百分点，且销售回款率下降 |
   | 区域性集中拖累 | 产品线视角下，单一大区的负向贡献至少占该产品线环比的 50% |

   数字必须能在计算结果里原样找到。找不到就写「本数据无法支持」。没有 `DEEPSEEK_API_KEY` 时不生成说明，页面保留结构化结果。

## 表关系

六张表的字段见原型第 4 节。实现约定：

- 一笔出库一张发票。回款全部挂发票，因此可以按产品归因，不做无发票分摊。
- `region_id` 一律等于代理商所属大区。
- 账龄只来自 `fact_ar_snapshot`。快照在该月回款入账之后写下，不用以后月份的回款回写历史余额。
- 经营流水覆盖 2025-11-01 至 2026-10-31。另有一笔 2024-11-15、金额 100 元、当天结清的标记出库，只用来让老代理商的首次出库早于「近 12 个月」窗口。它不进入任何月末快照，也不进入 2026-09/10 的环比。
- 不建承诺、库存、汇率或直销客户表。

主问计算链：期间净销售和期间回款 → 销售回款率及环比 → 回款与净销售贡献 → 交叉贡献 → 代理商贡献和账龄迁移。到期回款率只作对照。
