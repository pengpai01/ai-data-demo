## P0 主问

默认视角是大区，切片是华东。试剂产品线下降 -14.32pp，小于华东，所以不默认展开产品线。五个大区和三条产品线的净销售占比都 ≥ 5%，全部参评。

- 华东销售回款率 91.52% → 64.24%，环比 **-27.28pp**，净销售占比 41.07%。
- 回款额变化贡献 **-15.83pp**（回款额 16,290,320.00元 → 13,472,480.00元）。
- 净销售额变化贡献 **-11.45pp**（净销售额 17,800,000.00元 → 20,972,880.00元）。
- 两项都为负，各自都超过环比绝对值的 25%。未四舍五入时相加等于 -27.28pp。
- 拖累前三名都是 A 级代理商，净销售上升、回款额下降：
  - 锦程华东代理商，贡献 -7.84pp
  - 苏澜华东代理商，贡献 -7.09pp
  - 浙澜华东代理商，贡献 -6.72pp
- 计算信号：冲量出货抬高分母、大代理商延期、账龄恶化、促销折扣升但回款未跟。
- 华东 90+ 未清金额从上月的 0 增加到 1,930,240.00元，占比升到 4.14%。
- 月末 7 日净销售占比 24.00% → 62.62%。折扣率 8.00% → 11.51%。
- 到期回款率（辅助）89.59% → 73.82%，与销售回款率的 -27.28pp 不是同一个数。主结论不用它。

## P0 逾期

## 页面

- `GET /` 含标题「星澜诊断 · 经营分析助手」和角标「演示数据·虚构」。
- `app.js` 启动时读取 `/api/meta` 的主问并 `POST /api/ask`。
- 主问响应含结论、KPI、两张图、归因；`view=product` 与 `view=region` 会切换结论。
- 每张图和结论句带有口径、过滤条件和贡献表。

另用无头 Chrome 打开 http://127.0.0.1:8000 ：进入后自动出现华东 -27.28pp 的主问报告；点「产品线视角」后结论变为试剂 -14.32pp；点「数字从哪来」能看到口径、过滤条件和贡献表；在输入框发送趋势问句后，左侧换成近 6 个月折线，结论含 64.24%；发送「承诺回款」只在对话里说暂不支持，左侧报告保留；点「返回主问」回到 -27.28pp。页面没有脚本错误。
